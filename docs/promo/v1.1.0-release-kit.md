# FramePulse v1.1.0 — Release & Promo Kit

## Ringkasan Rilis v1.1.0
- **Riwayat & Perbandingan Sesi Lokal (`BenchmarkHistoryStore`)**: menyimpan hingga 20 sesi benchmark terakhir dan menghitung selisih (`Δ Avg FPS`, `Δ 1% Low`, `Δ Peak °C`) dibanding sesi sebelumnya.
- **Mode Kepadatan & Preset HUD (`HudPresetManager`)**: beralih cepat antara `COMPACT` dan `DETAILED` serta menyimpan konfigurasi HUD per game (`opacityPercent`, `1% Low`, `Peak Temp`, tombol `REC`).
- **Integrasi Terpadu (`FramePulseV110Bridge`)**: menyatukan penyimpanan sesi pasca-benchmark dan konfigurasi HUD aktif dalam satu jalur yang ringan.

## Draf Post Singkat (X / Komunitas Android)
